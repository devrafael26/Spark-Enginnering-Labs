# Spark Engineering Lab

Laboratórios práticos para aprofundar conhecimentos em Apache Spark e Databricks, explorando desde os fundamentos internos do Spark até performance, otimização, Delta Lake e Structured Streaming.

A proposta é desenvolver uma visão de engenharia: entender o funcionamento do Spark, analisar sua execução, testar hipóteses e documentar resultados.
